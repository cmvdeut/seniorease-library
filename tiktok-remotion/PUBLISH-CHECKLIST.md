# Publish Checklist — SeniorEase Social Videos

Gebruik deze lijst na het renderen van je EN/NL batches.

## 1) Render batches

```bash
npm run render:scripts:en
npm run render:scripts:nl
```

Output staat in `tiktok-remotion/output/`.

## 2) Bestandscontrole (voor upload)

- Vertical format: 1080x1920
- Duur: 9-20 seconden
- Geen zwarte balken
- CTA zichtbaar in laatste 2-3 seconden
- Geen typefouten in hook/body/CTA

## 3) TikTok (Engels)

Gebruik bestanden met `seniorease-script-en-...mp4`.

- Caption format:
  - Problem + benefit + CTA
  - Example: `Bought the same book twice? Scan first with SeniorEase. Download on Google Play.`
- Hashtags: 3-5 stuks (niet teveel)
  - Suggested: `#bookcollector #vinylcollector #androidapp #seniorease #notsubscription`
- Cover frame: kies frame met duidelijke hooktekst
- Link in bio: Play Store URL moet kloppen

## 4) Facebook (Nederlands)

Gebruik bestanden met `seniorease-script-nl-...mp4`.

- Caption format:
  - Herkenbaar probleem + praktische oplossing + CTA
  - Example: `Alweer dubbel gekocht? Scan eerst met SeniorEase en zie meteen wat je al hebt.`
- Hashtags: max 2-4 (Facebook minder hashtag-zwaar)
  - Suggested: `#collectie #boeken #vinyl #SeniorEase`
- Eerste zin extra belangrijk (zonder op “meer weergeven” te klikken)

## 5) Publicatieplanning (simpel)

- TikTok EN: 1 video per dag
- Facebook NL: 3-4 video's per week
- Beste tijd testen in 2 weken, daarna vaste slots kiezen

## 6) Meetpunten per platform

Per post noteren:
- Views
- 3-second hold / watch time
- Profiel- of linkklikken
- Reacties / saves / shares

Na 10 posts:
- Stop zwakke hooks
- Verdubbel top 3 hooks
- Hergebruik winnaars met nieuwe visuals

## 7) Veiligheidscheck vóór bulk posten

- Play Store link werkt
- Domein `seniorease.eu` werkt zonder redirect-lus
- Sitemap in Search Console ingediend: `https://seniorease.eu/sitemap.xml`
- Branding consistent: SeniorEase-kleuren en app screenshots
