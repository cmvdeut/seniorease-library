# 🔑 Vercel API Token - Optioneel

## Als je een API Token wilt gebruiken:

### Stap 1: Token Aanmaken

1. **Ga naar Vercel Dashboard**
2. **Klik op je profiel** (rechtsboven)
3. **Kies:** "Settings"
4. **Ga naar:** "Tokens" (in het linker menu)
5. **Klik:** "Create Token"
6. **Vul in:**
   - Name: `seniorease-library-debug`
   - Expiration: (kies een periode)
7. **Klik:** "Create Token"
8. **Kopieer de token** (je ziet hem maar 1x!)

### Stap 2: Token Delen

**⚠️ BELANGRIJK:** Deel de token alleen als je dat wilt. Het geeft toegang tot je Vercel account.

**Alternatief:** We kunnen ook via de browser kijken als je ingelogd bent.
